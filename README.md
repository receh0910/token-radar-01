A token launch radar: it reads a sealed snapshot of every protocol DefiLlama tracks, finds the ones that still record no token and are not a wrapped or staked product of one that trades, ranks them by the implied value of their launch, and serves a sortable, filterable dashboard with a per-protocol detail view and a farm plan for each.

## Run it

```sh
node main.ts --input snapshot.json --output out
```
